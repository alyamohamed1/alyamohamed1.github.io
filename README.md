# Alya Altawash — Portfolio

Static site (HTML/CSS/JS, no build step). Open `index.html` through any web host or a local server.

## Run locally
```
python3 -m http.server 8000
```
then visit http://localhost:8000 (opening the file directly blocks the 3D models).

## Edit
- Project content: `assets/projects.js` (PROJECTS list at the top)
- Contact links: `assets/site.js` (CONFIG at the top)
- CV download: replace `assets/Alya_Mohamed_CV.pdf`
- Styles: `assets/style.css`

## Hosting
Hosted with GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
